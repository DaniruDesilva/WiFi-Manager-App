# Wi-Fi QR Generator 📱✨

A premium, modern Flutter application that makes sharing and connecting to Wi-Fi networks completely seamless. Generate beautiful QR codes, create printable guest cards, write Wi-Fi details to NFC tags, and pin networks directly to your Android home screen.

## 🌟 Features

*   **Generate Wi-Fi QR Codes:** Instantly create scannable QR codes for your home, office, or guest networks.
*   **Built-in Scanner:** Fast and reliable QR code scanner to instantly connect to new networks.
*   **Android Home Screen Widget:** Pin your most frequently shared network directly to your home screen. Guests can scan it without you even opening the app!
*   **Guest Cards (PDF/Image Export):** Generate beautifully designed, printable "Guest Wi-Fi" cards in 4 premium templates (Minimal, Gradient, Dark, and Typographic).
*   **NFC Tag Writer:** Tap your phone to an NFC tag to instantly write your Wi-Fi credentials to it. Guests can then simply tap the tag to connect!
*   **Speed Test:** Integrated internet speed test tool.
*   **Secure History:** Saves your generated and scanned networks locally on your device for quick access. 
*   **Beautiful UI/UX:** Built with a stunning "Electric Blue" theme, smooth micro-animations, and full Dark Mode support.
*   **Privacy First:** 100% offline. Your network passwords never leave your device.

## 🚀 Getting Started

### Prerequisites
*   [Flutter SDK](https://flutter.dev/docs/get-started/install) (version 3.3.0 or higher)
*   Android Studio / VS Code
*   An Android or iOS device for testing (NFC and camera features require physical hardware)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YourUsername/wifi-qr-generator.git
    cd wifi-qr-generator
    ```

2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the app:**
    ```bash
    flutter run
    ```
